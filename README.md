# TaskAutomation
This Python script automates the process of renaming all files in a specified folder using a sequential naming pattern like file_1.txt, file_2.jpg, etc.

## Features

- Renames all files in a folder to a uniform pattern.
- Automatically retains the original file extensions.
- Skips subfolders and directories.
- Easy to customize and extend.

## Requirements

- Python 3.11
